# CS121_project_2
## "Guess a Number Game" Algorithm
```
1. Ask user for name, stored as string
2. Generate a random number from 1 to 100, using srand
3. Ask user for number
4. Give user feedback based on how close they were to number
5. Keep repeating until user enters the correct number
6. Keep track of amount of turns
7. Give feedback based on how many turns it took to guess number
turns, guesses, and the hidden number are stored as ints
```
